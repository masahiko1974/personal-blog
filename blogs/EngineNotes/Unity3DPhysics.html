Unity3D物理系统内容梳理

Unity3D物理三个基础且常见的模块：刚体、碰撞体、关节。

刚体（Rigidbody）

刚体相关API

  1. 施加力

    // 对刚体施加一个垂直向上的瞬时冲量
rigidbody.AddForce(Vector3.up * 10, ForceMode.Impulse);
// 对刚体施加绕世界坐标系Y轴的持续扭矩（旋转力矩）
rigidbody.AddTorque(Vector3.up * 5, ForceMode.Force);
// 在刚体局部坐标系上方1单位处（世界坐标位置）施加向前的力
// Vector3.forward 使用世界坐标系方向，transform.up 获取物体局部坐标系上方偏
rb.AddForceAtPosition(Vector3.forward * 20, transform.position + transform.up);

    力的模式

    • ForceMode.Force：施加一个持续力，影响刚体的收到力的效果。适用风力、推力。
    • ForceMode.Impulse：给予瞬间冲量，直接改变刚体速度。适用爆炸、跳跃。
    • ForceMode.VelocityChange：精确控制速度，用于急停或瞬移。
    • ForceMode.Acceleration：给予加速度，忽略质量。用于匀加速运动。

  2. 速度控制

    rigidbody.velocity = new Vector3(0, 10, 0); // 设置刚体向上移动
rigidbody.angularVelocity = Vector3.up * 5; // 绕 Y 轴旋转

  3. 约束

    rigidbody.constraints = RigidbodyConstraints.FreezePositionX; // 冻结 X 轴移动

碰撞体（Collider）

  • 碰撞体的类型

    • 简单形状：使用 Box Collider、Sphere Collider 或 Capsule Collider，性能高效。
    • 复杂形状：静态物体用 Mesh Collider，动态物体用 Compound Collider。
    • 特殊用途：地形用 Terrain Collider，车辆用 Wheel Collider。

  • 物体发生碰撞的必要条件：两个物体都必须带有碰撞器Collider，其中一个物体还必须带有Rigidbody刚体。

  • 碰撞器和触发器

    • 碰撞器（Collider）：是物理交互的基础组件，用于检测物体之间的碰撞。
    • 触发器（Trigger）：是碰撞器的一个属性（Is Trigger），用于检测物体是否进入某个区域，但不会产生物理碰撞效果。

碰撞体相关API

碰撞器可触发 OnCollisionEnter/Stay/Exit。

触发器可触发 OnTriggerEnter/Stay/Exit。

关节（joint）

关节组件依赖刚体组件

在 Unity3D 中，与物理关节（Joints）相关的组件主要用于模拟刚体之间的约束或连接关系。

在力学观点下，运动分为6个自由度，沿着xyz轴的位移，绕xyz轴的旋转。通过将某些轴的位移和旋转给一些限制条件来达到限制刚体运动的目的。 五大关节：

  • Hinge Joint（铰链关节）：绕单轴旋转。典型应用：门、摆钟、机械臂。
  • Spring Joint（弹簧关节）：弹性连接。典型应用：弹簧、绳索、悬挂系统。
  • Fixed Joint（固定关节）：刚性固定。典型应用：焊接、拼接物体。
  • Character Joint（角色关节）：球型关节。角色四肢的摆动
  • Configurable Joint（可配置关节）：高度自定义。

射线检测

射线检测（Raycasting）用于从某个起点沿指定方向发射一条不可见的射线，检测与场景中碰撞体（Collider）的相交情况。

核心 API 及功能

API功能
Physics.Raycast发射直线射线，检测首个碰撞体
Physics.RaycastAll检测射线路径上所有碰撞体（返回数组）
Physics.RaycastNonAlloc无GC版本，减少内存分配（性能优化）

参数中必须指定射线起点（世界坐标系）和射线方向（需归一化），返回是否与任何碰撞体相交。

可直接传入 Ray 参数，替代单独的 origin 和 direction 参数。Ray 是表示一条射线的结构体。

可选参数包括

  • out RaycastHit hitInfo ：存储命中信息（碰撞体、交点、法线等）。
  • float maxDistance ：射线最大检测距离。
  • int layerMask ：层级过滤。
  • QueryTriggerInteraction queryTriggerInteraction ：是否检测触发器。

与摄像机结合的射线发射

  • Camera.ScreenPointToRay:将屏幕坐标转换为射线（从摄像机发射到场景）。

    典型应用：鼠标点击选中物体、触摸交互。

    Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);
if (Physics.Raycast(ray, out hit, 100f)) {
    Debug.Log("点击到物体：" + hit.collider.name);
}

  • Camera.ViewportPointToRay:将视口坐标（归一化的屏幕坐标，范围 [0,1]）转换为射线。

    Ray ray = Camera.main.ViewportPointToRay(new Vector3(0.5f, 0.5f, 0)); // 屏幕中心
Physics.Raycast(ray, out hit);

性能优化技巧

  1. **层级过滤（LayerMask）**可结合位运算
  2. 限制检测距离
  3. 避免高频调用
  4. 使用 RaycastNonAlloc
  5. 可视化射线：使用 Debug.DrawRay 在Scene视图中绘制射线。
Ray ray = new Ray(transform.position, transform.forward);
Debug.DrawRay(ray.origin, ray.direction * 10f, Color.red, 1f);
