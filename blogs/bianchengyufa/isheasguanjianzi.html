is和as关键字的用法与区别

在C#编程中，类型转换是一个常见的操作，尤其是在处理继承、接口和多态时。C# 提供了多种方式来进行类型转换，其中 is 和 as 是两个非常常用的关键字。

is 关键字

is 关键字用于检查一个对象是否属于某个特定类型，或者是否实现了某个接口。它的返回值是一个布尔值（true 或 false），表示对象是否与目标类型兼容。

示例：

object obj = "Hello, World!";
if (obj is string)
{
    Console.WriteLine("obj 是一个字符串");
}

在这个例子中，obj 是一个 object 类型的变量，但它实际上存储了一个字符串。is 关键字检查 obj 是否是 string 类型，如果是，则输出 "obj 是一个字符串"。

特点：

  • is 关键字只进行类型检查，不进行实际的类型转换。
  • 如果类型检查成功，可以在 if 语句块内安全地进行类型转换。

模式匹配中的 is

在C# 7.0 及更高版本中，is 关键字可以与模式匹配结合使用，进一步简化代码。

示例：

if (obj is string str)
{
    Console.WriteLine("obj 是一个字符串: " + str);
}

在这个例子中，is 不仅检查 obj 是否是 string 类型，还将其转换为 string 类型并赋值给 str 变量。

as 关键字

as 关键字用于将对象转换为指定的类型。如果转换成功，返回目标类型的引用；如果转换失败（即对象不是目标类型），则返回 null。

示例：

object obj = "Hello, World!";
string str = obj as string;
if (str != null)
{
    Console.WriteLine("转换成功: " + str);
}
else
{
    Console.WriteLine("转换失败");
}

在这个例子中，obj 是一个 object 类型的变量，但它存储了一个字符串。as 关键字尝试将 obj 转换为 string 类型。如果转换成功，str 将包含字符串的值；如果转换失败，str 将为 null。

特点：

  • as 关键字只适用于引用类型（如类、接口、数组等），不能用于值类型（如 int、bool 等）。
  • 如果转换失败，as 不会抛出异常，而是返回 null。
  • 由于 as 返回 null 时不会抛出异常，因此在处理可能失败的转换时，as 比强制类型转换更安全。

强制类型转换 vs as

C# 支持强制类型转换（即显式类型转换）。强制类型转换使用 (TargetType) 语法。

示例：

object obj = "Hello, World!";
string str = (string)obj;

强制类型转换的特点：

  • 如果转换失败，会抛出 InvalidCastException 异常。
  • 适用于所有类型（包括值类型和引用类型）。

使用 as 进行类型转换：

  • 强制类型转换在失败时会抛出异常，而 as 不会。
  • 强制类型转换适用于值类型，而 as 仅适用于引用类型。

总结

  • is 关键字用于类型检查，返回布尔值，不进行类型转换。
  • as 关键字用于类型转换，返回目标类型的引用或 null，适用于引用类型。
  • 强制类型转换适用于所有类型，但在失败时会抛出异常。
  • 在C# 7.0 及以上版本中，is 可以与模式匹配结合使用，简化代码。
