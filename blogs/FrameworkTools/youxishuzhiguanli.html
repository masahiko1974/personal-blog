GameParamTool 配置工具开发文档

本工具的核心功能是在编辑模式下将Excel表格中的游戏配置数据转换为Unity中的ScriptableObject或二进制文件。通过自动化生成代码和资源，减少手动编写数据类和资源管理的工作量。工具的主要功能包括：

  • Excel数据解析：读取Excel文件并解析为C#对象
  • 代码生成：根据Excel表结构自动生成数据类和容器类代码
  • 资源生成：将Excel数据转换为ScriptableObject或二进制文件
  • 可视化界面：提供Unity编辑器窗口，方便用户配置和操作

设计思路

1. 存储方案选择

游戏配置数据(如怪物属性、道具参数等)的存储方案主要分为两类：

  1. Unity管理型存储
    • 典型代表：ScriptableObject
    • 优势：可由Unity直接管理，方便可视化编辑，支持资源依赖管理
    • 劣势：修改数据结构后已有数据会丢失，编辑界面不够友好
  2. 独立文件存储
    • 包括：二进制、JSON、XML等格式
    • 优势：轻量级，加载速度快，平台无关性强
    • 劣势：难以直接编辑，缺乏可视化支持

考虑到Unity工作流的集成性，推荐使用ScriptableObject方案。但工具同时支持两种方案，以满足不同场景需求。

2. 数据编辑与代码生成

为解决配置编辑的痛点，采用Excel作为数据维护入口：

  • Excel提供友好的表格编辑环境，便于策划人员理解和使用
  • 支持数据验证、公式计算等高级功能

系统自动生成以下代码文件：

数据类

对应Excel表的单行数据，字段类型和名称由Excel表头定义

  • ScriptableObject模式

    [Serializable]
public class ExampleData {
    public int id;
    public string name;
}

  • 二进制模式

    [MessagePackObject]
public class ExampleData {
    [Key(0)] public int id;
    [Key(1)] public string name;
}

容器类

生成用于存储和管理数据类实例的容器类。

  • ScriptableObject模式

    容器类包含一个 List<T> 和一个 Dictionary<TKey, TValue>，采用List存储数据，运行时转换为Dictionary，以解决ScriptableObject无法直接序列化Dictionary的问题。

    生成的容器类会继承自 ScriptableObject，并包含将 List<T> 转换为 Dictionary<TKey, TValue> 的方法（ToDictionary）。ToDictionary()方法保证键值对的正确映射。

    public class ExampleDataContainer : ScriptableObject {
    public List<ExampleData> dataList = new();
    public Dictionary<int, ExampleData> dataDic = new();
    public void ToDictionary() {
        foreach (var item in dataList) {
            dataDic.Add(item.id, item);
        }
    }
}

  • 二进制模式

    包含一个Dictionary类型的字段 dataDic

    生成的数据类和容器类会使用 MessagePack 的序列化标记（[MessagePackObject] 和 [Key]），以便将数据序列化为二进制格式。

    [MessagePackObject]
public class ExampleDataContainer {
    [Key(0)] public Dictionary<int, ExampleData> dataDic = new();
}

管理类

记录所有容器类的必要信息，便于游戏运行时加载配置数据。

  • ScriptableObject模式

    public class ContainerDir : ScriptableObject
{
	public List<string> ConList = new();// 容器资源引用列表
}
public abstract class BaseContainer : ScriptableObject
{
	public abstract void ToDictionary();
}

  • 二进制模式（待完善）

3. 资源生成机制

由于数据类型在运行时才能确定，系统大量使用反射机制实现数据对象的动态创建和属性赋值。

对于ScriptableObject方案，通过ScriptableObject.CreateInstance创建容器实例，并使用AssetDatabase.CreateAsset将数据持久化为Unity资产。

在二进制方案中，选用高性能序列化框架MessagePack处理数据序列化，其标记特性（如[MessagePackObject]、[Key]）确保了类型信息的正确保存和还原。这种设计既保证了数据转换的可靠性，又为不同存储方案提供了统一的处理框架。

模块设计

工具的整体架构分为以下几个模块：

GameParamWindow - 编辑器界面

功能

  • 提供本工具的图形化界面
  • 管理Excel文件路径、命名空间、输出类型等配置偏好
  • 提供生成代码和资源文件的操作入口

主要方法

  • private static void ShowWindow() 显示配置窗口实例，确保单例模式。
  • private void OnGUI() 绘制编辑器窗口界面，包含以下主要配置项：
    • Excel文件路径设置
    • 命名空间设置
    • 输出文件类型选择
    • 输出容器类路径设置
    • 输出资源文件路径设置
    • 生成代码和资源的功能按钮
  • private string BrowseForFolder(string path) 浏览文件夹对话框，用于选择各类文件路径，确保路径合法性。

ExcelReader - Excel文件读取

功能

  • 查找指定目录下所有Excel文件。
  • 查找Excel表中作为Key的列。
  • 将以上找到的信息作为元组缓存在列表中。

主要方法

  • public List<(DataTable, int)> GetExcelTables(string filepath); 获得指定路径下的所有Excel文件的DataTable集合和对应的key列索引，并实现数据缓存。
  • private int GetKeyIndex(DataTable table); 获取表格中标记为"key"的列索引，大小写不敏感。

CodeCreator - 代码生成

功能

  • 根据DataTable对象生成不同模式下的数据类和容器类代码
  • 生成不同模式下的目录类代码
  • 支持基本值类型、结构体类型、List类型。

主要方法

  • public string CreateSObjCode(DataTable table, int keyIndex) 使用CodeBuilder类动态拼接代码字符串，生成ScriptableObject模式下的数据类和容器类代码。

  • public string CreateSObjDirCode() 生成ScriptableObject模式下的目录类和基础容器类

  • public string CreateBinCode(DataTable table, int keyIndex) 使用CodeBuilder类动态拼接代码字符串，生成二进制模式下的数据类和容器类代码。

ExcelParser - Excel表格解析

功能

  • 将Excel表中的一行数据解析为指定类型的对象。

  • 支持复杂类型（如List<T>、结构体）的解析。

主要方法：

  • public static T ParseFromExcelRow<T>(DataRow row) where T : new() 创建T类型的对象，遍历Excel行的每一列数据，调用SetFieldValue方法设置对象的字段值。

  • private static void SetFieldValue<T>(T instance, FieldInfo field, object value) 根据字段类型调用不同的解析方法：

    • List<T>：调用ParseList方法。

    • 结构体：调用ParseStruct方法。

    • 枚举：调用Enum.Parse方法。

    • 基本类型：直接使用Convert.ChangeType方法转换。

  • ParseList(Type listType, string value) 字符串使用分号（中英文不敏感）分隔List元素，将字符串解析为List<T>对象。

  • ParseStruct(Type structType, string value) 字符串使用逗号（中英文不敏感）分隔不同字段，解析每个字段并设置结构体的值。

AssetCreator - 资源生成

功能

  • 动态获取对应的数据类和容器类的 Type。

  • 利用生成的数据类和容器类生成不同模式下的游戏资源（.asset或二进制文件）。

主要方法

  • GetTypes(DataTable table) 根据Excel表的名称，动态获取对应的数据类和容器类的Type。

  • CreateScriptableObject(DataTable table)

    1. 创建容器类的实例，并通过反射获取dataList字段。
    2. 遍历Excel表的每一行数据，调用methodBase方法解析出数据类的实例，添加到dataList中。
    3. 返回生成的ScriptableObject实例。

  • CreateSObjectDir(List<(DataTable, int)> collection) 创建Directory类的实例，并通过反射获取ConList字段。遍历所有Excel表，将每个表的容器类名称添加到ConList中。

  • CreateByte(DataTable table, int keyIndex)

    1. 创建容器类的实例，并通过反射获取dataDict字段。
    2. 遍历Excel表的每一行数据，调用methodBase方法解析出数据类的实例，添加到dataDict中。
    3. 使用MessagePackSerializer将容器对象序列化为二进制数据，并返回字节数组。

ParamAssetCreator - 功能协调

功能

  • 将整个工具的各个模块（如Excel读取、代码生成、资源生成等）整合在一起。
  • 提供一个统一的接口供外部调用。

主要方法

  • public ParamAssetCreator() 在构造函数中初始化 ExcelReader、CodeCreator 和 AssetCreator，并获取 ExcelParser 的 ParseFromExcelRow 方法，并将其传递给 AssetCreator，用于解析Excel数据。

  • CreateCode(CreateConfig config)

    1. 调用ExcelReader读取Excel文件。

    2. 根据输出类型（ScriptableObject或二进制）调用CodeCreator的相应方法生成代码。

    3. 将生成的代码保存到指定路径。

  • CreateAsset(CreateConfig config)

    1. 调用ExcelReader读取Excel文件。
    2. 根据输出类型（ScriptableObject或二进制）调用AssetCreator的相应方法生成资源。
    3. 将生成的资源保存到指定路径。

使用说明

  1. 确保项目中已安装以下依赖库：

    • MessagePack（用于二进制序列化）
    • ExcelDataReader（用于读取Excel文件）

  2. Excel文件需按以下规则设计表格结构：

    行号描述示例值1示例值2
    0变量名行idname
    1变量类型行intstring
    2主键标记行key
    3注释行唯一ID名字
    4+数据起始行1001哥布林

    注意：

    • 主键列必须在第2行标记key，且唯一
    • 复杂类型支持：
      • List<T>：数据用;分隔（如1;2;3），T可以是普通值类型，结构体
      • 结构体：数据用,分隔（如10,20，需提前定义结构体类型），字段可以是普通值类型和枚举类型
      • 枚举：直接填写枚举值名称

  3. GameParam Tool 窗口说明

    • Excel File Path：Excel文件所在目录（如Resources/Excel）

    • Namespace：生成代码的命名空间（如GameConfig）

    • Output File Type：选择Object（ScriptableObject）或Binary

    • Output Class Path：生成代码的保存路径（如Scripts/Generated）

    • Output File Path：生成资源的保存路径（如Resources/Configs）

    • 生成代码：

      • 点击 Build Code，工具会根据Excel表生成数据类和容器类代码。

      • 生成的代码文件位于配置的Output Class Path路径下。

    • 生成资源：

      • 点击 Build Asset，工具会读取Excel数据并生成.asset或.mako文件。
      • 生成的文件位于配置的Output File Path路径下。
