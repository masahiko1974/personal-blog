AssetBundle 资源加载工具开发文档

本系统用于在Unity项目中运行时加载和管理AssetBundle（AB包）。系统通过模块化设计，实现了AB包的加载、卸载、依赖管理、资源加载等功能，提供同步和异步加载AB包资源的方式，同时确保在多线程环境下的并发安全。

模块介绍

ABDepCounter - 引用计数与依赖管理

功能

  • 管理AB包的引用计数。
  • 递归处理AB包的依赖关系，确保依赖包的引用计数正确增减。
  • 在引用计数为0时，标记AB包为可卸载状态。

主要方法

  • AddRef(string abName)：增加AB包的引用计数，递归增加其依赖包的引用计数。
  • ReleaseRef(string abName)：减少AB包的引用计数，递归减少其依赖包的引用计数，返回需要卸载的AB包列表。

ABLoader - AB包的加载与卸载

功能

  • 加载和卸载AB包。
  • 管理AB包的依赖信息。
  • 提供同步和异步加载AB包的接口。

主要方法

  • LoadMainAB()：初始化时加载主AB包，并读取所有AB包的依赖信息。
  • LoadABAsync(string abName)：异步加载指定的AB包，递归加载其依赖包。
  • LoadABSync(string abName)：同步加载指定的AB包，递归加载其依赖包。
  • UnLoadAB(string abName)：卸载指定的AB包。

ABResMgr - 资源管理

功能

  • 管理从AB包中加载的资源。
  • 提供同步和异步加载资源的接口。
  • 管理资源的实例化与卸载。

主要方法

  • LoadResAsync(string abName, string resName, UnityAction<Object> action)：异步加载指定AB包中的资源，并在加载完成后执行回调。
  • LoadResAsync<T>(string abName, string resName, UnityAction<T> action)：异步加载指定AB包中的泛型资源，并在加载完成后执行回调。
  • LoadResSync(string abName, string resName)：同步加载指定AB包中的资源。
  • LoadResSync<T>(string abName, string resName)：同步加载指定AB包中的泛型资源。
  • UnLoad(Object obj)：卸载指定的资源实例，并减少相关AB包的引用计数。

AssetBundleExts - 异步加载扩展

功能

  • 提供异步加载AB包和资源的扩展方法。
  • 封装了 TaskCompletionSource，简化异步操作的处理。

主要方法

  • WaitForABReq(string bundlePath)：异步加载指定路径的AB包，返回 Task<AssetBundle>。
  • WaitForResReq(this AssetBundle ab, string resName, System.Type type)：异步加载指定AB包中的资源，返回 Task<Object>。
  • WaitForResReq<T>(this AssetBundle ab, string resName)：异步加载指定AB包中的泛型资源，返回 Task<T>。

设计思路

1. 引用计数与依赖管理

  • 以AB包为单位进行引用计数，与Unity的设计理念一致，简化实现。
  • 通过 ABDepCounter 管理AB包的引用计数，确保在卸载资源时能够自动释放不再使用的AB包。
  • 递归处理AB包的依赖关系，确保依赖包的引用计数正确增减。

2. 异步加载与并发安全

  • 使用 Task 封装加载AB包和资源的方法
  • 使用 ConcurrentDictionary 确保在多线程环境下的数据一致性。

3. 资源管理

  • 通过 ABResMgr 管理从AB包中加载的资源，提供同步和异步加载接口。
  • 在卸载资源时，自动减少相关AB包的引用计数，并释放不再使用的AB包。

执行流程

  1. 初始化：
    • ABResMgr 初始化时，创建 ABLoader 和 ABDepCounter。
    • ABLoader 加载主AB包并解析所有AB包的依赖关系。
  2. 加载资源：
    • 调用 ABResMgr.LoadResAsync() 或 LoadResSync() 加载资源。
    • ABResMgr 调用 ABLoader.LoadABAsync() 或 LoadABSync() 加载AB包。
    • ABLoader 递归加载AB包的依赖包，并最终加载目标AB包。
    • ABResMgr 从AB包中加载资源，并增加AB包的引用计数。
  3. 卸载资源：
    • 调用 ABResMgr.UnLoad() 卸载资源。
    • ABResMgr 调用 ABDepCounter.ReleaseRef() 减少AB包的引用计数。
    • 如果AB包的引用计数降为0，则调用 ABLoader.UnLoadAB() 卸载AB包。

注意事项

  1. 加载模式冲突：
    • 在加载资源时，需确保同一AB包的加载模式（同步或异步）一致，避免冲突。
  2. 异步加载的取消：
    • 当前系统不支持异步加载的取消操作，如需取消加载任务，需手动处理。
  3. 依赖关系：
    • 需手动确保AB包之间的依赖关系不存在环形依赖。
